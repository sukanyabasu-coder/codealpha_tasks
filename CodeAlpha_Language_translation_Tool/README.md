# Language Translation Tool

A simple Language Translation Tool built using Python and the `deep-translator` library.  
This project translates text from one language to another using Google Translate services.

---

## Features

- Translate text into multiple languages
- Automatic language detection
- Simple and beginner-friendly implementation
- Iterative translation support
- Exception handling for invalid inputs
- Supports multiple languages

---

## Technologies Used

- Python
- Jupyter Notebook
- deep-translator

---

## Libraries Used

```python
from deep_translator import GoogleTranslator
```

---

## Supported Languages

- English
- Hindi
- French
- German
- Spanish
- Japanese
- Korean
- Italian

---

## How It Works

1. User enters text
2. Program automatically detects the source language
3. User selects the target language
4. The text gets translated using Google Translate services
5. The translated text is displayed as output

---

## Installation

Install the required library using:

```python
pip install deep-translator
```

---

## Run the Project

Open the Jupyter Notebook and run all cells.
