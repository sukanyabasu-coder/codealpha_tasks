# CodeAlpha FAQ Chatbot

This project is developed as part of the CodeAlpha Artificial Intelligence Internship.

## Project Overview

An AI-powered FAQ chatbot that answers user questions using:

* NLP preprocessing
* TF-IDF Vectorization
* Cosine Similarity

## Technologies Used

* Python
* Pandas
* Scikit-learn
* NLP

## Features

* FAQ-based chatbot
* Similarity matching
* Interactive chatbot loop
* Beginner-friendly implementation
